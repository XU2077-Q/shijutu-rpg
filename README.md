一八九五年，一个湖南读书人的路。

俯视角、可走的场景、像素小人、水墨立绘、任务系统。**没有战斗。**

## 三条硬约束

1. **网页版 `index.html` 一个字都不能改。** 它是只读数据源。
2. **游戏完全离线。** 这不是技术偏好，是上架资质 ——
   TapTap 国内对「不联网 + 无内购」的游戏只要求防沉迷与隐私合规，**不需要版号**
   （版号排队以年计，是最大的拦路虎）。一旦联网或加内购，就掉进「正式上线」那一档。
   **Android 导出预设里的 INTERNET 权限必须是关的。**
3. **原作的文学性不能毁。** 旁白占 2193 拍里的 1594 拍（73%），那是这部作品的本体。
   所以原文只做脊梁，新内容由**扩写读本**提供，两者永不混写。

## 数据是怎么来的

```
index.html ─┐
            ├─→ tools/export_story.js ─→ data/*.json ─→ Godot 运行时
docx ───────┘
```

```
node tools/export_story.js
```

导出器会：

1. 从 `index.html` 切出数据层求值（**只读，不写**）
2. 把 18 处函数值字段编成**声明式条件 AST**（认不出来的形状一律 throw，绝不静默丢弃）
3. 从 docx 机械抽取 31 条扩写（不靠手抄，手抄会引入错字）
4. 按 `data/expansion_map.json` 把扩写接进场景图
5. 跑一整套校验，不合格 `exit 1`

### 它验什么

- **原文逐字未变** —— 扩写是另起节点（`x1`…`x31`）插进图里，原文的 `beats` 一个字节不动。
  导出器把「改动前」与「改动后」两份副本逐拍比对。
- **读本 ↔ 原文逐字一致** —— 把读本里**非扩写**段落拼成整块，拿原文每一拍去里面找。
  实测 2200 拍命中 2199，唯一落空的那一拍正是第 14 条 `replace` 所顶替的。
  这条检查与 `replace` 的语义**互相印证**，两边都对上了。
- **原文指纹** —— 原文剧本的 SHA-256 锁在 `data/origin.sha256`。剧本一漂，立刻炸。
- 悬空引用、未知节拍类型、BBCode 元字符、扩写锚点是否存在……

## 跑测试

双击 **`跑测试.bat`**，或者：

```
node tools/export_story.js                                    # 第一步：剧本数据
godot --headless --path . res://tests/test_main.tscn          # 第二步：游戏侧
```

两步都要过。中间隔着 JSON 序列化与 Godot 的解析，所以不能互相替代 ——
第一步验「导出那一刻对不对」，第二步验「游戏读到的这份对不对」。

## 工程结构

```
autoload/   DataDB → CondEval → GameState → SaveManager   （顺序即 project.godot 里的注册顺序）
data/       导出器产物（story/notes/markers/endings/expansions）
            + 手写文件（expansion_map / rooms / story_map / quests）
scenes/     world/（房间 玩家 交互物）  ui/（对话框 立绘 任务栏 时局图 史实注 存档格）  boot/
scripts/    world/  ui/  vn/
art/        bg/ portraits/ props/ walk/ ui/ fonts/
tools/      export_story.js  docx.js  gen_art.js  ← **绝不导出**（里面有 API key 的位置）
tests/      极简测试跑架 + unit/
```

**为什么测试不用 GUT**：要测的几乎全是数据不变量（bid 唯一、脊梁保序、存档往返、AST 求值），
都是纯函数，不需要场景树、替身对象、JUnit 报告。为这点事引入一个几千行的编辑器插件，
换来的是「它自己升级会破坏我们的测试」。`tests/test_case.gd` 只有三条契约，
真需要替身对象了再换也不迟，测试文件本身不用改。

## 美术

- **立绘 / 背景**：水墨写意 + 版画质感 + 宣纸底（参照《明末：饿殍千里行》），
  与现有 UI 的宣纸、朱砂、印章、水墨时局图是一套。
- **走动的小人**：像素风。这个混搭站得住 —— *To the Moon* 本身就是
  「像素小人走世界 + 精细立绘对话框」。
- 行走图**不用 AI 生成**：图像模型画不出前后一致的四向行走序列。
  像素画恰好能从颜色网格直接生成，所以手写网格 + 脚本出图。

> *To the Moon* 的素材打包在 `.rgssad` 里，**不会解包复用** —— 那是受版权保护的，
> 商业发行不能用。它只当比例参考。
